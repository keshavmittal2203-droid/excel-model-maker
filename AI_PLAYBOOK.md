# Universal AI Playbook: Excel-Only Financial Model Engine

This playbook gives any AI agent deterministic, step-by-step instructions to take researched company data from allowlisted sources and produce:
1. An authentic, template-preserving, error-free **16-sheet Excel financial model (`.xlsx`)** built directly from `originals/Marksans Keshav.xlsx` and versioned deltas in `work/sources/`.
2. A native Microsoft Excel COM 16.0 recalculated model with **zero formula errors**, validated dynamic `BS!C40:N40` balance checks (`={col}38-{col}16`), responsive sensitivity tables, and 15 landscape PDF preview schedules.

> [!IMPORTANT]
> **Excel-Only Architecture**: PowerPoint generation has been completely retired. Historical `.pptx` files in `originals/` are inert catalog archives and are not read or generated by the active engine.

---

## 0. Non-Negotiable Safety & Provenance Rules

1. **Never modify `originals/`**: Treat every file in `originals/` as an immutable read-only reference. Always write outputs to a dedicated staging directory (e.g. `staging/v16_reproducibility/` or `candidates/<run_dir>/`).
2. **Verify master template integrity**: Run `python verify_sources.py` before building. The active 16-sheet master template `originals/Marksans Keshav.xlsx` must match SHA-256 `4dc79842855e5d1e689a2f5ca1de22c34be72fb09c0c0f9dd3a95818e10737d0` byte-for-byte.
3. **Locked allowlist sources only**: Use only the websites named in the master workbook plus Screener.in:
   - Screener.in
   - Yahoo Finance
   - NSE India
   - Trading Economics
   - Top Stock Research
   - Investing.com
   - Prime Investor
   Do NOT use company investor relations, BSE, RBI, Damodaran, search snippets, or unverified AI figures.
4. **No balancing plugs or forced ties**: Never introduce balancing plugs to force balance sheets to zero. True differences between published financial statement line items and integer-rounded sub-schedules must remain transparently exposed in `BS!C40:N40` (`={col}38-{col}16`).
5. **Factual inputs vs analyst assumptions**: Company-specific facts (e.g. segment EBITDA, standalone net cash, vertical subsidiary book values) cannot be relabeled as analyst assumptions. If a required company-specific fact is absent from allowlisted sources, the valuation MUST be marked `Unavailable` (`N/A`).
6. **Governance gate**: Candidates remain unapproved until a human reviewer explicitly signs off. Autonomous approval is strictly prohibited; manifests and progress logs must record `ready: false` and `human_pack_approval: pending`.

## 2. Reproducible Four-Target Build Workflow

### Step 1: Verify Originals
```bash
python verify_sources.py
```
Both master template copies must pass SHA-256 verification.

### Step 2: Reproduce Models with Single Documented Command
Execute the self-contained orchestrator to reproduce all four targets (MM, LTM, CLEAN, EDELWEISS) into a clean staging directory:

```powershell
python work/build_template_v16_models.py --output-dir staging/v16_reproducibility
# OR via the unified package builder:
python build_package.py --template-v16 --output-dir staging/v16_reproducibility
```

For headless or non-COM environments, add `--skip-com`:
```powershell
python work/build_template_v16_models.py --output-dir staging/v16_reproducibility --skip-com
```

### Step 3: Automated Audit & Recalculation Checks
When run with Microsoft Excel COM 16.0, the orchestrator automatically:
1. Rebuilds formulas with `excel.CalculateFullRebuild()`.
2. Verifies **0 formula errors** across all 16 sheets for every company (64 sheets total).
3. Verifies that `BS!C40:N40` contains dynamic formula `={col}38-{col}16` in all 12 periods (`FY15–FY26E`).
4. Verifies historical balance sheet tie (`FY15–FY25 = 0.00 Cr`).
5. Checks authentic FY26E balance differences:
   - **MM**: `+₹7,677.49 Cr` (conglomerate NBFC loan book gap exposed; forecast **BLOCKED**; valuation **Unavailable**).
   - **LTM**: `+₹1.00 Cr` (integer rounding delta in Screener sub-schedules; **UNRECONCILED**; valuation supported at **₹2,620.24 / share**).
   - **CLEAN**: `−₹1.13 Cr` (rounding delta in Screener sub-schedules; **UNRECONCILED**; valuation supported at **₹393.03 / share**).
   - **EDELWEISS**: `+₹1.00 Cr` (integer rounding delta in Screener sub-schedules; **UNRECONCILED**; industrial DCF prohibited, valuation **Unavailable**).
6. Confirms cost of capital parameters (WACC and Blume-adjusted beta):
   - MM: WACC 11.97%, Blume beta 1.3164 (raw 1.4746)
   - LTM: WACC 12.48%, Blume beta 1.1018 (raw 1.1526)
   - CLEAN: WACC 13.19%, Blume beta 1.2141 (raw 1.3212)
   - EDELWEISS: WACC 10.47%, Blume beta 1.7487 (raw 2.1231)
7. Tests dynamic sensitivity perturbation and exact restoration on supported models (`LTM` and `CLEAN`).
8. Exports 15 landscape PDF preview schedules per company (60 total) in `staging/v16_reproducibility/<TARGET>/previews/`.
9. Compares generated workbooks cell-by-cell against delivered handoff workbooks (`deliverables/V16_user_handoff/workbooks/`) and confirms **0 cell mismatches**.
10. Writes `staging/v16_reproducibility/<TARGET>/package.manifest.json` and `staging/v16_reproducibility/reproducibility_summary.json`.
