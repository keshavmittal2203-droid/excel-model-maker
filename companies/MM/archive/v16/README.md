# Archived M&M V16 input files

These package/input files belong to the superseded V16 workflow. They are retained for historical reproducibility only and are not inputs to the active M&M Template V17 build. The old package includes presentation-related fields and unsupported share-count, CapEx, and standalone valuation claims; do not use those values as V17 evidence.

The active V17 source registry is `docs/MM_SOURCE_REGISTRY.md`. The active build uses the 16-sheet master plus the committed Screener and Yahoo Finance snapshots specified by the locked allowlist.
